# gpspy

Small Python tool that reads NMEA sentences from a GPS receiver on a serial port (`/dev/ttyACM0`) and pretty-prints the GSA data: fix mode, 2D/3D fix and the satellites in use.

- **Status:** archived 2026-10 — experiment (Dec 2022)
- **Platform:** Python 3.9+ (poetry), pyserial, pynmea2
- **Related:** `~/Code/_archiv/elektronik/gps-spy` (Pico firmware), `~/Code/_archiv/elektronik/SensorPlatform`
